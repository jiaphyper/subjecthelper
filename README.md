# SubjectHelper 作业平台

Next.js 15 + SQLite（better-sqlite3），单个项目，本地即可运行。

## 运行
```bash
npm install
npm run dev          # 开发模式 http://localhost:3000
# 正式使用：
npm run build && npm start
```
首次启动自动创建数据库 `data/app.db`，以及默认管理员 **admin / admin123**（登录后请先修改密码）。
备份数据只需复制 `data/` 文件夹。

## 角色与功能
**管理员 admin**
- 学校（org）、学科管理
- 账号：单个创建 / Excel 批量导入（用户名 | 姓名 | 角色 | 密码 | 学校）、改学校、重置密码、停用、删除
- 题库（按学科）：选择题 Excel、词汇 Excel（英文 | 中文 | 英文释义）、挖空填词 Word（表格第一列加粗为空，第二列为干扰词）
- 查看所有组别、所有任务和成绩（只读）

**教师 teacher**
- 我的学生：从本校学生中勾选绑定
- 组别：自己创建、管理成员（只能看到自己的组别）
- 布置任务：选学科、题型（选择 / 连线英-中或英-释义 / 挖空填词，可多选）、数量、组别，发布时随机抽题并冻结
- 成绩：每个学生 3 次的分数、最高分、逐题详情，导出 Excel

**学生 student**
- 每个任务最多 3 次机会，开始作答即占用一次
- 逐题「校验」：第一次校验的结果计分；可「再来一次」练习（不计分）或「下一题」
- 成绩取 3 次中的最高分；机会用完后可查看正确答案
